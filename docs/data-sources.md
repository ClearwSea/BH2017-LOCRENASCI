# 数据与规则来源

| 内容 | 来源与处理 |
| --- | --- |
| 基础表单、原生协议 | 从使用者提供的1.9/2.4输入提取和转换，在本地生成 |
| 跨版本补行 | 从2.4参考数据选择，投影到1.9序列化结构；251表索引见profiles/table-recipes.json |
| 商店 | 维护者自行设计的分类、商品池、币种、价格和购买规则；物品ID引用游戏输入 |
| 材料导航 | 统一入口和按ID的兼容修改；只记录列表编辑，不携带材料属性表 |
| 每日使命、重复掉落、触摸、补给策略 | 项目行为与兼容规则，分别保存代码或声明配置 |
| 外传、轮回、料理、委托目录 | 从原表派生；其中部分金币价格、刷新等为项目规则 |
| 无尽温度校准 | 项目公式派生配置，生成公式见prepare_endless_hp_climate.py |
| 委托稀有度 | `src/rules/commission-rarity.json`保存基于官方数据修改的MapId=1稀有度兼容分布 |
| 模拟对手名称 | `src/rules/endless-bot-names.json`由维护者自行收集和编写 |
| 补给图、公告、舰桥横幅、图标 | 维护者基于官方素材制作的配套图片，通过独立补充资源包提供 |
| 7.x中缺少的旧CG | 引用自官方其他版本提取的游戏CG，由外部补充资源包提供；不适用源码开源许可证，不进入源码或CI，不计入该7.x输入转换结果 |
| 虚拟好友配置 | 不提供玩家快照；需要时自行定义示例档案，现有模块支持未配置时返回空列表 |

独立JSON的文件形式不决定来源。由原表派生的catalog仍由输入生成；项目自拟规则可随源码保存；混合配置按字段说明来源。完整材料属性、剧情文本和资源文件不作为规则配置放入源码。
