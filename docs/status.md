# 功能范围

BH2017-LOCRENASCI以2026年11月2日版本为基础，提供Python本地服务端、客户端兼容适配与运行组件源码。可自行开发、使用生成脚本或命令行，也可选择配套Windows图形构建器。各组件职责如下。

| 组件 | 功能 |
| --- | --- |
| Python本地服务端 | 按客户端协议处理本地业务、缓存、商店、每日使命、掉落等项目规则 |
| Windows构建器 | 选择客户端与资源、检查路径、查看参考输入、管理签名、显示进度与日志、停止构建 |
| 表单与资源生成 | 恢复251张基础表，应用材料导航及项目规则，生成有效服务端表、派生目录和客户端数据 |
| 客户端适配 | 应用ARMv7原生兼容补丁，修补提取的客户端资源，转换7.x语音与视频 |
| APK组装 | 编译Python承载层和Android启动界面，组装、对齐、签名，输出APK与配套视频ZIP |
| Android启动界面 | 手动启动、资源与存档导入、存档备份和导出、正常1×/辅助20×伤害选择 |

完整构建使用1.9 APK、2.4参考APK、7.x PC Windows资源及独立补充ZIP。生成的APK内置主资源和服务端，视频通过同次构建的外置包导入；兼容存档另行提供。

游戏和Python运行时为ARM32。TANGO环境下的ABI适配、启动错误显示及伤害设置见[Android兼容说明](android-compatibility.md)。

扩展其他客户端、原生库或资源组合时，需要相应的字段映射、补丁和转换规则。[构建流程与扩展](roadmap.md)介绍实现位置与适配入口。
